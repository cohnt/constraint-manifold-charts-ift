# RB-Y1 IKFast solvers

The analytic inverse kinematics for the RB-Y1's two 7-DOF arms, generated by
[OpenRAVE's IKFast](http://openrave.org/docs/latest_stable/openravepy/ikfast/).

```
cpp/rby1_ik/ikfast.h                 IKFast's runtime header (Apache-2.0, OpenRAVE)
cpp/rby1_ik/rainbow_left_arm_ik.cpp  generated transform6d solver, left arm
cpp/rby1_ik/rainbow_right_arm_ik.cpp generated transform6d solver, right arm
```

## Building

There is no CMake here and **no Drake dependency** — these are plain CPython extension modules
built by the project's `setup.py`:

```bash
cd ..                 # the rby1-whole-body folder
pip install -e .      # builds rainbow_left_arm_ik and rainbow_right_arm_ik, takes seconds
python -c "import rainbow_left_arm_ik, rainbow_right_arm_ik; print('ok')"
```

The extensions land in `src/` as `rainbow_{left,right}_arm_ik.cpython-312-*.so` and are
gitignored. **Python 3.12 is required** — the modules are built against that ABI.

`src/rby1_analytic_ik.py` wraps them, selects among IKFast's eight solution branches, and works
over both `float` and `AutoDiffXd`.

## Provenance

Generated with IKFast version `0x1000004a`, `transform6d` solver, on 2024-10-11, from
`../models/ruby/rby1_description_drake/`. The generated code carries an Apache-2.0 grant that
IKFast writes into every solver it emits; `ikfast.h` is separately Apache-2.0 and has been
modified here (a `#include "Python.h"` block, marked inline with the notice Apache-2.0 §4(b)
requires). See [`../THIRD_PARTY.md`](../THIRD_PARTY.md).

# Third-party content

The MIT licence in `LICENSE` covers this project's own source — everything under `src/`
and `scripts/`, plus the model-directives YAMLs in `models/`. Several assets under
`models/` are third party and carry their own terms, listed here.

## `models/universal_robots/` — UR robot description

Vendored from [ros-industrial/universal_robot](https://github.com/ros-industrial/universal_robot/tree/6507bb6756d0065d49b76230ff55f875f099a827/ur_description)
(commit `6507bb6`), recorded in `ur_description/meta-information.json`. Licensed under
**Apache License 2.0**; the full text is kept at `models/universal_robots/LICENSE.txt`.

This is a **pruned** copy: only the UR5e is used by this project, so the UR3, UR3e, UR5,
UR10, UR10e and UR16e descriptions and meshes have been removed. Use the source link
above for the unmodified original.

Two files under `ur_description/` are *generated*, not upstream, and are outputs of this
project's own code (`scripts/visualize_grasp_selection.py`), so they fall under the MIT
licence above:
- `urdf/ur5e_drake_collision_obj.urdf`
- `meshes/ur5e/visual/*.obj` (per-colour OBJs split out of the upstream `.dae` meshes;
  the geometry itself remains Apache-2.0 from upstream)

## `models/wsg_finray/` — Schunk WSG-50 gripper with Finray fingers

Taken from [nepfaff/scene_gen_policy](https://github.com/nepfaff/scene_gen_policy), which
is released under the **MIT License**.

`wsg50_110_finray_fingers_box_collision.sdf` references
`package://drake_models/wsg_50_description/meshes/wsg_body.gltf`, supplied by
[Drake](https://drake.mit.edu) (BSD 3-Clause). The `_obj.sdf` variant is generated by
this project and swaps that reference for a local OBJ.

## `models/mug/`, `models/assets/shelves.sdf`

Simple authored scene geometry, distributed under this project's MIT licence.

## Dependencies (not vendored)

- **[Drake](https://drake.mit.edu)** — BSD 3-Clause. Supplies `pydrake` and the SNOPT
  solver. Drake's precompiled binaries bundle a private SNOPT build that requires no
  separate licence when invoked through `SnoptSolver`.
- **[EAIK](https://github.com/OstermD/EAIK)** — BSD 3-Clause. The analytic IK solver this
  work builds on. If you use it, cite the EAIK paper:
  <https://ieeexplore.ieee.org/document/11122599>.
